# Source handling

Public GitHub is the home for independently authored findings, operating documents supplied by the owner, inventories and native build work. Original community PDFs, extracted text, workflow templates, private conversation and unreviewed archives remain in ignored .local/checkpoint. This is a publication boundary, not lost work.

Per candidate, record exact URL, date, commit/hash, license text reviewed, assets/dependency licenses, reuse decision and remaining uncertainty. An API license label is preliminary evidence, not a whole-artifact clearance. Free access does not establish redistribution permission. Do not assume an MIT repository licenses its related paid packs or media.

Do not store tokens, signed attachment URLs, session state or private account identifiers in public evidence. Synthetic probes use explicit dummy values. Download scripts never execute acquired code. Retain original snapshots and separate new versions rather than overwriting evidence.

No blanket license is assigned to the repository or its contents.
