## Acceptance evidence

List stable check IDs under each outcome. Record pass, fail, unverified or justified not-applicable; include the test, screenshot, API/data check or provider evidence path and date. Record visual acceptance separately. Unassessed scope has no percentage until its denominator is defined.

## Scope read and inspected

Record relevant files, source documents, designs and operational evidence read completely. List unread/inaccessible scope explicitly.

## Next execution batch

List ordered meaningful tasks, dependencies and finish conditions. Aim for 10–20 only when supported by the authorized work.

## Blockers and required user actions

Identify the blocked outcome, actual cause, smallest required action and independent work that can proceed.

## Dated cycle history

Append date, before/after counts and percentages, completed outcomes, new scope, regressions and supporting evidence. Retain prior baselines.

## Resume and cleanup

Record active services, disposable data, pending cleanup, exact next step and handoff link. No credentials.
